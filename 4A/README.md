# CS180 Project 4A Website — SHU CAO

Open `index.html` in a web browser. All required images and styles are bundled under `assets/` and `style.css`. The Google Fonts CDN is optional; the page falls back to local fonts when offline.

Content: A.1 original pairs, A.2 initial 12-point matches and refined 16-point homographies, A.3 two rectifications, A.4 three planar mosaics, A.5 cylindrical panoramas.

The refined 16-point homographies are intentionally distinguished from the initial 12-point diagnostic plots.
